# 共生之躯 Symbiotic Body

- **來源**：[Pinterest](https://www.pinterest.com/pin/1149473504922877930/)
- **作品**：海報底部標著「The time｜探索 AI 在服裝領域的運用」，看起來是 AI 生成的服裝概念系列，實際作者不明。
- **檔案**：`assets/reference-poster.jpg`（1920×1080，只留在本機、不進 git）。Pinterest 上的圖是轉了 90° 的直式，這裡已經轉正成橫式。
- **版權**：只作為風格參考。

## 風格重點

**配色：展間白 + 炭灰外殼 + 血肉粉紅**

| 用途 | 色碼 | 備註 |
| --- | --- | --- |
| 背景 | 純白 | 像博物館展牆，什麼都不加 |
| 外殼 | 炭灰到黑 | 鱗片、甲片、斗篷，佔畫面大部分 |
| 內臟 | 粉紅到暗紅 | 全畫面唯一的暖色，集中在每具身體的胸腹 |
| 頭部點綴 | 鍍鉻白藍 + 紅色耳件 | 只有約一半的人物有 |

**構圖**
- 13 具人物一字排開，像標本或時裝秀的 lineup。
- 兩端最高大、往中間逐漸變小，底部排成一條往下彎的弧線，中間最低。
- 標題放在弧線上方的凹處：細黑體中文、字距很開，下面一行粗體英文小字。
- 左上、右上各一段灰色小字說明，最底下一行小小的出處標記。

**調性**
冷靜、像學術圖鑑，但內容是有點駭人的打開身體。用大量留白和細字標題把衝擊感壓住。

## 調性頁（`index.html`）

- **13 具人物是自己重畫的**（`src/gen.py`），不是從原圖切的：照每一具按鈕上寫的頭部（鍍鉻頭顱／黑色兜帽）、外殼（鱗片、甲片、褶層、斗篷、立領、繭殼）和內臟（腸、心臟、肋骨、脊椎、盆腔……）參數化畫成扁平向量，尺寸和原本一樣，所以弧線排列不變。白底 JPEG 用 multiply 疊在紙色上。重新產生：在 `src/` 執行 `uv run python gen.py`。
- 滑過任一具：其他的淡出、這一具微微浮起，旁邊出現放大鏡跟著游標檢視細節。
- 下方的編號會變成這一具的編號，列出頭、外殼、露出的部位。這些描述是我看圖寫的，不在原海報上。
- 鍵盤可以用 Tab 和 ← → 逐一檢視；手機上整排可以左右滑。
- 左上的英文、右上的中文說明都是這頁自己寫的「標本說明」，不再轉寫原海報的小字。

## 可以拿到網頁上的手法

1. **一字排開的系列**：同一主題的多個變體排成一列，比網格更像「收藏」。
2. **用尺寸排出弧線**：大小由兩端往中間遞減，讓中間留出放標題的空間。
3. **白底 + 單一暖色**：大面積冷灰，只有內容的核心（內臟）是暖色。
4. **放大鏡檢視**：細節豐富的圖不用另開頁面，直接在原地放大。
5. **細字大字距的標題**：有衝擊性的畫面配很輕的標題，反而更冷。
