## 風格重點

**配色：五個平塗色，沒有漸層和陰影**

| 用途 | 色碼 | 佔畫面 |
| --- | --- | --- |
| 地面（紙） | `#F2FCF8` | 約 38% |
| 深藍 | `#023D5C` | 約 33%，線條、陰影面、夜空 |
| 薄荷 | `#A8EAE0` | 招牌底、遮陽棚 |
| 橘 | `#F86C42` | 招牌、條紋、燈籠 |
| 蜜桃 | `#FCCC9A` | 豬頭招牌、牆面點綴 |

深藍同時當線稿和暗面，所以整張畫只靠「深藍 vs 紙色」就撐住結構，其他三色只是填色。

**構圖**
- 從高處往下看的一點透視窄巷，兩側建物往中間傾斜，盡頭是黑色夜空。
- 兩邊塞滿招牌：漢字、片假名、英文混雜（「義太夫」「スナック歩美」「GOYA」「LANCE」），還有豬頭、魚、青蛙形狀的立體招牌。
- 巷子中央站著一個很小的女孩，是全畫面唯一的人，也是視線終點。

**調性**
懷舊的昭和橫丁，但用很乾淨的扁平色塊畫，熱鬧卻安靜。

## 調性頁（`index.html`）

- **巷景是自己重畫的**（`src/gen.py`），不是原圖：同樣是一點透視的窄巷，但建物、招牌、燈籠、小孩和貓都是新的，招牌店名（喫茶灯台、焼鳥とり吉、スナック千鶴……）全是虛構的。先用五個顏色畫成一張 SVG，2 倍解析度渲染後依最接近的顏色拆成四個色層，再縮小，所以邊緣是平滑的。重新產生：在 `src/` 執行 `uv run python gen.py`。
- 紙色當背景，每層用 CSS 變數填色，所以整條巷子可以整組換色。
- **四個時間**：白天（原作的配色）、傍晚、下雨、深夜。後三組配色是我另配的。系統開深色模式時，頁面會直接從「深夜」開始。
- **指向色票**：只留下那個顏色，其他淡出，看每個顏色負責畫了哪些地方。

## 可以拿到網頁上的手法

1. **用五色以內的平塗**：一個深色同時當線條和暗面，結構就穩了，其他顏色可以隨便換。
2. **色層 = CSS 變數**：插畫拆成遮罩層後，主題切換就是換一組變數，連插畫一起變。
3. **密集的周邊 + 空的中央**：兩側塞滿細節，中間留一條空路，視線自然往裡走。
4. **單一小人物當視線終點**：在很滿的畫面裡放一個很小的人，給尺度也給故事。
