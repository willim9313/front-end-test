# Yerko《哈姆雷特》跨頁

- **來源**：[Pinterest](https://www.pinterest.com/pin/1149473504922877027/)
- **作品**：Vladyslav Yerko（Владислав Єрко）插畫，莎士比亞《哈姆雷特》烏克蘭文版，Yurii Andrukhovych 譯，A-BA-BA-HA-LA-MA-HA 出版，2009。
- **檔案**：`assets/reference-spread.jpg`（2308×1780，Pinterest 原圖，只留在本機、不進 git）
- **版權**：插畫與排版有版權，只作為風格參考。不要裁切插畫放進任何會公開的頁面。

## 調性頁（`index.html`）

底圖是**這頁自己畫的石墨插畫**（`src/gen.py`），不是原跨頁：同一場景（第五幕結尾），但不畫人物，改畫四根長戟抬著蓋了深色斗篷的棺架，上面放著王冠和劍，兩側垂著旗幟；中縫一樣有一道石墨墨痕垂到文字區。用排線、雜訊和下緣漸隱做出石墨的質感，白底用 multiply 疊在紙底上。重新產生：在 `src/` 執行 `uv run python gen.py`。文字用即時文字排莎士比亞原文（公有領域）。可以切換 EN／中文，看看兩種文字放進同一個版面的感覺；本機有原圖（`assets/reference-spread.jpg`，不進 git）時會出現「Original」按鈕可以對照；點角色名，其他人的台詞會淡出；共用詩行的後半句由 JS 量出前半句的寬度後接上。中文是為這頁自己翻的。

## 畫面

第五幕結尾。Fortinbras 下令「讓四名隊長把哈姆雷特像軍人一樣抬上高台」，四名騎士扛著蓋著斗篷的遺體。

## 風格重點

**配色：黑白，加一個暖灰褐**

| 用途 | 色碼 | 備註 |
| --- | --- | --- |
| 紙 | `#F1F1F1` | 帶細紙紋，不是純白 |
| 插畫墨色 | `#242424` | 石墨或炭筆的層次，從近黑到淺灰 |
| 內文 | `#0C0C0C` | 近黑 |
| 角色名 | `#967E6C` | 唯一的顏色，低彩度的暖灰褐 |

**插畫和版面的關係**
- 插畫佔跨頁上半部約 55%，人物在腰部被切掉，邊緣用乾筆或拓印的筆觸散進紙裡，沒有外框。
- 構圖左右對稱（左右各 2 名騎士），中間被斗篷連起來。
- 中縫有一道墨痕從插畫往下垂到文字區，同時把左右兩欄文字分開，等於拿筆觸來當欄線。

**字體排印**
- 內文是古典舊式襯線字，字號偏大、行距鬆，詩行靠左對齊、右邊不齊。
- 角色名用全大寫、字距很開，配上上面那個褐色，放在台詞上方，比內文往左凸出（hanging）。
- 共用詩行（半行接續）的寫法：接續的半行往右縮排，接在上一句結束的位置，例如「Слухати негайно」「Перш за все」。這是戲劇排版特有的細節。
- 文字區四周留白很大，兩欄之間的距離也大，中間由墨痕佔據。

## 可以拿到網頁上的手法

1. **插畫溶進內容**：主圖的下緣不切直線，用筆觸做 mask，讓圖散進文字區。
2. **用筆觸當分隔**：欄線、段落分隔改用一道墨痕，不用 1px 線。
3. **只有一個低彩度強調色**：只給標籤或角色名用，其他全部黑白。
4. **半行縮排**：對話、問答、時間軸這類「接續上一句」的內容，用縮排接在上一行結尾，不換新段落。
5. **懸掛標籤**：標籤往左凸出內文，視覺上像頁邊註。

## 字體候選（需要支援西里爾字母或中文時）

- 西文和西里爾字母：EB Garamond、Cormorant Garamond、PT Serif，都有西里爾字母。
- 中文：Noto Serif TC，或源樣明體這類舊式明體。
- 原書用的字體還沒確認。
