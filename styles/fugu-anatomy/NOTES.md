# Fugu Anatomy（三色網版印刷解剖圖）

- **來源**：[TeePublic](https://www.teepublic.com/poster-and-art/53169819-fugu-anatomy-tokyo) 上由 ppmid 設計並販售的「Fugu anatomy Tokyo」，經 [Pinterest](https://www.pinterest.com/pin/1149473504922081901/) 找到
- **檔案**：`assets/reference-poster.jpg`（630×630，Pinterest 最大尺寸）
- **版權**：屬設計者 ppmid，只作為風格參考。

## 風格重點

**配色：白紙 + 三個專色**

| 用途 | 色碼 | 備註 |
| --- | --- | --- |
| 紙 | 白 | |
| 深藍 | `#225A6E` | 魚身、輪廓、筷子和刀柄，佔最大面積 |
| 水藍 | `#1898B2` | 只在肚子裡的底色和刀身的反光 |
| 珊瑚紅 | `#E0685A` | 標題、標籤、引線、腸子、放大鏡 |

三色都帶明顯的網版磨損：字和色塊裡有白色的小斑點，邊緣略粗糙。

**構圖**
- 上方三行置中標題：小字「TOKYO CITY - JAPAN」、粗窄大字「FUGU ANATOMY」、圓體日文「フグの解剖学」。
- 中間是一條鼓起來的河豚，肚子剖開像解剖圖，用細引線拉出日文標籤。
- 右邊一個放大鏡圓圈，從魚身拉出來，放大看鱗片。
- 下方橫放一雙筷子和一把柳刃包丁，暗示「這是要吃的」。

**調性**
假正經的科學圖解。標籤內容是胡說八道（墨水、電、尖尖的球），但排得像真的解剖圖，笑點在這個落差。

## 調性頁（`index.html`）

- **三個色版**：插畫是自己重新畫的（不是描原圖），分成深藍、水藍、珊瑚紅三個色版，各自填色後疊起來。進場時一版一版「刷」上去，後兩版先錯開一點再對齊。
  - 構圖刻意和原作不同：河豚朝左、肚子剖開用大頭針固定、背上有白色肋骨、標籤排在魚的下方、放大鏡在右上看鱗片、下方只放一雙筷子。
  - 產生方式在 `src/`：`gen.py` 畫出三個 SVG 色版，`render.js`（Playwright）轉成 PNG，`distress.py` 加上網版磨損斑點。改構圖就改 `gen.py`，在 `src/` 裡依序執行三支（`uv run python gen.py && node render.js && uv run python distress.py`），再把產出的 `plate-*.png` 複製到 `assets/`。
- **拉開色版**：右邊三個色票可以把任一色版拿掉，看每個顏色各負責了什麼。例如拿掉珊瑚紅，標籤、引線、腸子和放大鏡一起消失，只剩藍色的魚。
- **器官說明**：標籤和標題是即時文字，點標籤會在右邊顯示一段胡說八道的說明，放大鏡也可以點。標題（Field Guide No. 7／Inside a Fugu／ふぐのなかみ）、五個標籤（非常墨、ダメ、ほね、根性、ふくらむ練習）和說明都是這頁另寫的，沒有沿用原作的文字。插圖裡的器官造型仍和原作的笑點相近；要改造型得改 `src/gen.py` 重新產生色版。
- 標題加了網版磨損的斑點（用雜訊遮罩做）。

## 可以拿到網頁上的手法

1. **少數幾個專色**：三個顏色就夠了，每個顏色負責明確的角色（主體、點綴、文字）。
2. **網版磨損質感**：雜訊遮罩打在文字和色塊上，讓數位畫面有印刷的手感。
3. **假正經的圖解**：用圖解、標籤、引線這種正式格式來講好玩的內容。
4. **色版分離的互動**：讓使用者把顏色一層層拿掉，看到設計是怎麼疊出來的。
