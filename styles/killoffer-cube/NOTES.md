# Killoffer 立方體漫畫（等角格子 + 閱讀順序圖）

- **來源**：[Pinterest](https://www.pinterest.com/pin/1149473504922081896/)（標題「Patrice Killofer comics」，作者名在 Pinterest 上拼錯了，正確是 Killoffer）
- **作品**：法國漫畫家 Patrice Killoffer 的短篇，畫上簽名「Killoffer 93」。他是 OuBaPo（潛在漫畫工坊）成員，這類用規則限制來創作的漫畫是 OuBaPo 的路數；依一篇 ResearchGate 論文的圖說，這張刊在 OuBaPo 合集《Oupus 1》（L'Association，1997），還沒看到原書確認。
- **檔案**：
  - `assets/reference-comic.jpg`：Pinterest 原圖（400×576，最大尺寸，只留在本機、不進 git）
  - `assets/comic.png`：這頁自己畫的十二格立方體漫畫
- **版權**：只作為風格參考，不要公開發佈。

## 風格重點

**配色：純黑白**
只有黑和白，連灰都用網點和排線做。大面積的實心黑格和白格交錯，畫面節奏靠黑白比例。

**格子**
- 每一格是立方體的一個面（菱形），十八格組成一群等角立方體，整體像一個缺了一角的六角形。
- 右上角是立體字「VAP」，左上角附一張閱讀順序圖：六角形裡十八個點用一條線串起來，外圍三個箭頭表示要一邊讀一邊轉。
- 透視全部跟著格子走：每一格裡的牆、門、地板都順著菱形的方向畫。

**對白**
手寫大寫字母，泡泡很小，句子被拆在很多格裡，例如「C'EST / BIZARRE / J'AI / L'IMPRESSION / D'ÊTRE / SUIVI / TOUJOURS / À LA / MÊME HEURE」（真奇怪，我總覺得被跟蹤……總是在同一個時間）。

## 調性頁（`index.html`）

- **漫畫是自己重畫的**（`src/gen.py`），不是原圖：改成一個立方體、三個面各四格，共十二格。故事也是新的：圍條紋圍巾的小人扛梯子走過屋頂、跳進活板門、在滿是門的房間挑一扇、爬樓梯、架梯子爬出畫格，最後發現自己又站在立方體頂上。每一格先畫成 100×100 的平面小圖，再用仿射矩陣貼到菱形上，所以透視跟著面走。
- **閱讀順序圖**：用同一套幾何產生（`src/map.json`），頂面 → 右面 → 左面，外圍三個箭頭表示順時針轉。
- **播放器**：按「播放」或拖滑桿，路線會一格一格畫出來，游標跟著移動；也可以直接點圖上的點。格數由圖上的點數決定。
- **對白**：收合區裡是這則漫畫自己的法文小泡泡，下面附中文。
- 重新產生：在 `src/` 執行 `uv run python gen.py && node ../../../tools/render-svg.js comic.svg ../assets/comic.png --opaque`，再依 `map.json` 更新 `index.html` 裡的閱讀圖。

## 可以拿到網頁上的手法

1. **等角格子當版面**：卡片做成菱形、拼成立方體，比一般網格更有空間感。
2. **附一張「怎麼讀」的地圖**：非線性的內容（流程、導覽）旁邊給一張順序圖。
3. **路線逐步畫出**：用 stroke-dashoffset 讓路線一段一段長出來，對應目前步驟。
4. **黑白交錯的節奏**：黑底格和白底格交錯排，不用任何顏色也有層次。
