# Saluti da Torino（單色鈷藍編輯式海報）

- **來源**：[Pinterest](https://www.pinterest.com/pin/1149473504927630743/)；海報上署名「Illustrazione di Kalla」
- **原始出處**：以圖搜圖找到同一張圖在 Everpress 當作限量 T 恤設計「Torino」販售（1080×1577，是目前最大的版本）。Everpress 在本機網路連不上，賣家頁面還沒直接核對。
- **檔案**：原圖不進 git，只留在本機。
- **版權**：原海報屬原作者，只作為風格參考。騎士插圖裁自 1915 年圖版〈Statue en bronze d'Emmanuel Philibert à Turin〉（[Internet Archive，n79 頁](https://archive.org/details/materialsdocumen10unse/page/n79)，公有領域；不是 Kalla 重繪的版本），其他裝飾是自己畫的，見 `CREDITS.md`。

## 風格重點

**配色：一張紙、一個墨色**

| 用途 | 色碼 | 備註 |
| --- | --- | --- |
| 紙 | `#EBE9EC` | 偏冷的灰白，不是純白 |
| 鈷藍 | `#1048B8` | 文字、插畫、線條、按鈕全部用它，對紙 6.5:1 |

深色版把兩者對調成深藍底（`#0D1836`）配淺藍字（`#DBE2F4`）。

**構圖**
- 置中的海報式刊頭：小字「Saluti da」→ 銅版雕刻的騎馬像 → 大字「TORINO」→ 副標「Città magica」→ 一行斜體註記。
- 雕像的真實經緯度直排在左右兩側，上方兩角放藤蔓與飛蛾的角花。
- 下面是三欄報紙式內文，用雕刻風的首字 T 開頭，句尾帶上標編號，對應底下的腳註。

**字體排印**
- 從頭到尾只用 EB Garamond。
- 大標全大寫、字距大幅拉開；小標也是大寫。
- 圖說、腳註和簽名一律斜體。
- 層級只靠大小、全大寫和斜體三件事，從不加第二個顏色。

**調性**
老派的城市明信片和旅遊手冊：學術、有點浪漫，靠單色印刷的節制顯得高級。

## 調性頁（`index.html`）

- **裝飾是自己畫的**（`src/gen.py`）：蝙蝠、角花、雕刻首字 T 都用排線畫成 SVG，再用 `tools/render-svg.js` 轉成 PNG。頁面把它們當 alpha 遮罩、用目前主題的墨色填色，所以深淺色切換時插畫會一起變色。騎士圖是公有領域圖版。重新產生：在 `src/` 執行 `uv run python gen.py`，再依檔案開頭的說明轉 PNG。
- **三欄內文與腳註**：介紹杜林的短文是這頁自己寫的，上標編號可以跳到腳註再跳回來。
- **寫一張明信片**：左邊表單、右邊明信片即時預覽，有字數計算和必填檢查；郵戳文字沿著圓形路徑排。
- **Elementi**：把配色、字體、裝飾和按鈕整理成四格，當作這個風格的元件表。
- **深淺色切換**：跟著系統，也可以手動切換並記住選擇。

## 可以拿到網頁上的手法

1. **單一墨色**：整頁一個顏色，層級交給字級、大寫和斜體；深色版就是把紙和墨對調。
2. **插圖當遮罩**：黑白排線圖做成 alpha 遮罩，用 CSS 填色，換主題不用重畫。
3. **腳註與上標**：內容型頁面用編號腳註收補充資訊，主文保持乾淨。
4. **邊角小註記**：經緯度直排、角花這種小東西，讓置中的版面不會太空。
5. **直角、細線、底線連結**：按鈕直角、1–2px 框線、連結保留底線，維持印刷品的感覺。
