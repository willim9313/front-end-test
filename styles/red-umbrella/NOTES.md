# 雨天窗景，一把紅傘

- **來源**：[Pinterest](https://www.pinterest.com/pin/1149473504928232555/)（標題是「Wallpaper iphone aesthetic black and white」，作者不明，看起來可能是 AI 生成的手機桌布）
- **檔案**：`assets/reference.jpg`（736×1308，Pinterest 最大尺寸，只留在本機、不進 git）；`scene.jpg`、`fog.jpg` 是這頁自己重畫的街景和它的「起霧」版
- **版權**：作者不明，只作為風格參考。

## 風格重點

**配色：全灰階 + 一個紅**

| 用途 | 色碼 | 備註 |
| --- | --- | --- |
| 窗框、人影 | 接近純黑 | 剪影，沒有細節 |
| 街道、建築 | 灰階 | 濕地面的反光用淺灰塊 |
| 紅傘 | `#E4342A` 左右 | 全畫面唯一的顏色，大約只佔 0.4% |

**構圖**
- 從室內窗戶往下俯視雨中的十字路口，窗框把畫面切成幾塊，前景窗台上一杯咖啡。
- 斑馬線斜斜穿過畫面，紅傘的人正走在中間，是視線焦點。
- 細長的白色雨絲、濕地上的倒影，用最少的筆觸表現下雨。

**調性**
安靜、帶點電影感的旁觀視角：你在室內，看著外面的城市。

## 調性頁（`index.html`）

- **街景是自己重畫的**，不是原圖：改成從窗戶正上方俯視（原作是斜看路口），有行道樹、三台車、一把把灰色的傘，紅傘在斑馬線上；窗框是田字格，窗台上放一盆植物（原作是咖啡杯）。
  - 產生方式在 `src/`：`gen.py` 畫出 SVG，`render.js`（Playwright）轉成 PNG，`post.py` 加顆粒並做出保留紅傘的起霧版，直接寫進 `assets/`。在 `src/` 裡執行 `uv run python gen.py && node render.js && uv run python post.py`。

- 整頁 UI 也只用灰階加紅（標題下的短線、滑桿），延續「只有一個顏色」。
- **擦玻璃**：窗子一開始是起霧的，只有紅傘還看得清楚。用滑鼠移過或手指拖過就能擦出一塊清晰的區域，霧會慢慢再回來。
- **兩個滑桿**：雨量（玻璃上的雨絲多寡）和霧回來的速度；按鈕可以一次擦乾淨。
- 開啟「減少動態效果」時不畫雨絲，擦玻璃仍可用（那是使用者自己操作的）。
- 霧蓋住整張畫，包括窗框；真實的霧只會在玻璃上，這裡為了簡單沒有分開。

## 可以拿到網頁上的手法

1. **全灰階 + 一個強調色**：強調色只給最重要的一個東西，連 UI 都跟著守規則。
2. **擦掉遮罩來揭露內容**：canvas 用 destination-out 擦除，比點擊展開更有觸感。
3. **會自己回來的狀態**：遮罩慢慢重新覆蓋，讓互動有「時間」的感覺。
4. **前景框住畫面**：窗框、窗台、咖啡杯，讓觀者有一個「站的位置」。
