## 風格重點

**配色：影印灰，幾乎單色**

| 用途 | 色碼 | 備註 |
| --- | --- | --- |
| 紙 | `#E4E4E3` | 帶明顯顆粒和網點，像影印或報紙紙 |
| 墨 | `#2A2A2A` | 標題、細線、星芒 |
| 插畫 | 灰階照片質感 | 羽翼人物是古典雕像照片的拼貼，跟線條圖混用 |

**構圖**
- 一條極細的垂直軸線貫穿畫面中央，頂端是黑色星芒，人物沿著軸線斜斜墜落。
- 軸線周圍散落細線光芒、靶心圓、小星星、荊棘頭像這些神祕學符號。
- 左邊是標題，右邊是詩句，左下是小段落，右下是兩個小人形，四個角落都有東西但都很小。
- 四格打叉的小方塊（⊠⊠⊠⊠）當作裝飾標記，出現在左上和右邊中段。

**字體排印**
- 標題是極窄的高瘦大寫字，「THROUGH」的 T 和「FALL」的 F、L 筆畫往下拉長成刀刃，一路刺到畫面下半部。這是整張海報最有記憶點的地方。
- 詩句是細緻的高對比襯線大寫，置中排，最後一個字「AGAIN.」靠右收尾。
- 小段落用同一種襯線字縮得很小。署名用窄體粗字。

**調性**
帶有宗教感和神話感（伊卡洛斯墜落），但用影印質感和極細線條處理，冷而安靜。

## 調性頁（`index.html`）

- **插畫層是自己重畫的**（`src/gen.py`），不是原海報：細軸線頂端的星芒、右側一扇細光芒、頭朝下墜落的有翼人形（網點質感）、新月、靶心圓、飄落的羽毛和小星星，最後加上影印顆粒。白底用 multiply 疊在灰紙上。重新產生：在 `src/` 執行 `uv run python gen.py`。
- 右邊的詩句和左下的小段落也是這頁自己寫的，不轉抄原海報；只沿用標題和版面的想法。
- **捲動就是墜落**：頁面捲動時海報固定在畫面上，
  1. 標題的三道刀刃從字母底下慢慢往下長，
  2. 右邊的詩句一行一行浮現，
  3. 整張插畫先往下沉、微微傾斜，最後一段又浮回原位，對應「Ascent through fall」。
- 用 CSS 的 scroll-driven animation 做，不支援的瀏覽器（例如 Firefox）或開啟「減少動態效果」時，直接顯示完成的海報。
- 標題用 League Gothic（寬度軸開到最窄），每一行由 JS 量好寬度對齊原海報；「FALL」額外垂直拉長 1.4 倍，模仿原圖拉高的字形。
- 詩句用 Cormorant Garamond。原海報的 N 是特殊的反向造型，這裡沒有複製。

## 可以拿到網頁上的手法

1. **字母筆畫延伸成圖形**：把標題的某幾筆拉長，變成分隔線或指向下方內容的線條。
2. **細軸線串起散落元素**：一條極細的直線讓四散的小符號有秩序。
3. **影印顆粒**：灰紙 + 雜訊 + multiply，讓照片和線條圖看起來是同一次印刷。
4. **捲動驅動敘事**：固定畫面、讓捲動推進狀態，適合只有一個畫面但想講一段話的頁面。
