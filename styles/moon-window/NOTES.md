- **來源**：[Pinterest](https://www.pinterest.com/pin/1149473504925229254/)（標題「Asian poster design graphics」，原 Pin 網址叫「the-pious」）
- **作者**：不明。畫面上的「阿拉伯書法」、右上直排小字、左側段落都是不可讀的仿字，很可能是 AI 生成的海報。
- **檔案**：
  - `assets/reference.jpg`：Pinterest 原圖（736×977，最大尺寸，只留在本機、不進 git）
  - `assets/poster.jpg`、`assets/waterfall-mask.png`：這頁自己畫的海報和它的瀑布遮罩
- **版權**：作者不明，只作為風格參考。

## 風格重點

**配色**

| 用途 | 色碼 | 備註 |
| --- | --- | --- |
| 紙 | `#E8DDB0` | 帶黃的米色，佔畫面約一半 |
| 墨綠 | `#243A3A` 一帶 | 圓窗裡的拱廊、池水 |
| 灰藍 | `#608080` 一帶 | 瀑布 |
| 朱紅 | 約 `#D8402E` | 花、錦鯉、印章，全畫面的強調色 |

**構圖**
- 一個大正圓佔上半部，像中式園林的月洞門，裡面是另一個世界。
- 瀑布從圓裡流出、越過圓的邊界、落到下方的水面，是唯一「出界」的元素，把兩個世界接起來。
- 右下一位披頭巾的人坐在岸邊背對觀者，鴿子散飛，下方整片錦鯉。
- 四周留大量米色紙面，小字散在角落（左上書法、右上印章和直排字）。

**調性**
安靜、神聖、超現實。很密的裝飾細節被一個乾淨的幾何形（圓）收住。

## 調性頁（`index.html`）

- **海報是自己重畫的**（`src/gen.py`），不是原圖：圓窗裡改成月夜山景（月亮、三層遠山、松枝、懸崖），瀑布從崖上越過圓框落進錦鯉池；岸邊改成石燈籠和丹頂鶴，鴿子改成燕子，左上只放一枚印章。瀑布遮罩 `waterfall-mask.png` 用同一條路徑產生，所以流動光紋剛好對齊。重新產生：在 `src/` 執行 `uv run python gen.py`，再用 `node ../../../tools/render-svg.js` 把 `poster.svg` 轉成 `../assets/poster.jpg`、`fall.svg` 轉成 `../assets/waterfall-mask.png`。

- **瀑布在流**：用瀑布形狀當遮罩，疊一層往下捲動的光紋，只在瀑布範圍內流動。按鈕可以讓水停下來；開「減少動態效果」時預設就是停的。
- **池面漣漪**：點池面會擴散出被壓扁的橢圓漣漪（配合低視角）；瀑布流動時，落水處也會不定時冒出漣漪。
- **文字**：右上放這頁自己的直排小標「The Pious」（取自 Pin 網址）和一行句子。
- 頁面背景直接用海報的紙色，海報和頁面融成一張紙。

## 可以拿到網頁上的手法

1. **一個幾何形框住複雜內容**：圓、拱、方都行，裡面多亂外面就多空。
2. **讓一個元素出界**：瀑布從框裡流出來，破框的那一點就是視覺焦點。
3. **遮罩限定的動態**：動畫只在某個形狀裡發生，整張圖仍然是靜態插畫。
4. **頁面背景 = 作品紙色**：讓作品不像被「放在」頁面上，而是頁面本身。
