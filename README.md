# front-end-test

收集與整理我中意的視覺風格與 UI 元素，作為之後開發系統頁面時的設計參考庫。

## 用途

- **風格收藏**：記錄喜歡的整體視覺方向（配色、字體、版面、動態、質感）。
- **元素收藏**：保存可重用的介面元素範例（按鈕、卡片、導覽列、表單、表格、圖表區塊等）。
- **開發參考**：之後做系統頁面時，可以直接從這裡挑風格與元件，或交給 AI 依照這些參考產生頁面。

### Python 環境（uv）

插圖產生器（`styles/*/src/*.py`）和轉圖工具（`tools/render_svg.py`）用 [uv](https://docs.astral.sh/uv/) 管理：Python 版本釘在 `.python-version`（3.12），套件寫在 `pyproject.toml`、鎖在 `uv.lock`，`.venv/` 不進 git。

```
uv sync                         # 第一次：建立 .venv、裝好 Pillow（沒有 Python 也會自動下載）
cd styles/yerko-hamlet/src
uv run python gen.py            # 重新產生插圖
```

SVG 轉 PNG／JPEG 在 Windows 上走 `tools/render_svg.py`（無頭 Edge），有 Node + Playwright 的話也可以用 `tools/render-svg.js`。

本機預覽：在 repo 根目錄執行 `uv run python -m http.server`，再開 http://localhost:8000 就是**風格目錄**（`index.html`），可以依類型、配色、字體、手法和插圖素材狀態篩選，點卡片進入各風格頁。篩選條件會記在網址的 `#` 後面，可以加進書籤。

### 規格卡

每個風格都長得不一樣，但拿來用的人一定要知道的事用同一張**規格卡**整理：身分與授權、適用場景、色彩角色、可讀性對比、字體角色、版面、質感、動態（含減少動態時的行為）、Do / Don't。

- 目錄裡每張卡片右上角的「規格」，或任一風格頁右下角的「規格」都會打開它；風格頁那裡也有「← 目錄」可以回來。
- 每個顏色會自動算出對底色的對比，標出「文字可用」「只能大字」「只當色塊」；點色碼複製，或一鍵複製整組 CSS 變數。
- 資料只有一個來源：`overview/catalog.js`。欄位定義和寫法見 [`docs/style-spec.md`](docs/style-spec.md)。

新增或修改風格時：
1. 在 `overview/catalog.js` 加一筆資料，規格卡的欄位都要填（篩選用的分類只能用檔案開頭 `FACETS` 裡列出的值）。開目錄頁時，console 會列出還沒填的欄位。
2. 在風格頁的 `</body>` 前加上 `../../overview/catalog.js` 和 `../../overview/spec.js` 兩個 script（照其他風格頁抄）。
3. 開著上面的伺服器，執行 `node overview/tools/thumbs.js <資料夾名稱>` 重新截縮圖（不加名稱就是全部重截）。沒有 Node 的 Windows 可以改用 `powershell -ExecutionPolicy Bypass -File tools/thumbs.ps1 <資料夾名稱>`（用無頭 Edge 截圖）。
4. 改過頁面上的中日文字之後，字型子集要重做，否則新字會掉回系統字型：`tools/subset-font.sh "<字型名稱>" <字重> <輸出.woff2> <頁面檔案…>`（透過 Google Fonts 只取頁面用到的字，用法寫在檔案開頭）。
